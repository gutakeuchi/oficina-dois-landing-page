# Oficina Dois - Landing Page

Landing page responsiva para a Oficina Dois, com apresentação de serviços, processo de atendimento, builds, formulário de orçamento e perguntas frequentes.

## Visualizar localmente

Abra `dist/index.html` no navegador ou execute um servidor estático dentro da pasta `dist`.

## Estrutura

- `dist/index.html` - conteúdo da página
- `dist/styles.css` e `dist/logo.css` - estilos
- `dist/script.js` - interações
- `dist/assets/` - identidade visual
